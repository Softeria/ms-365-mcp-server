# Security Policy

## Security Maintainer

Security for this project is handled by
[Eirik Brandtzæg](https://github.com/eirikb) (eirikb@eirikb.no), the
project's main developer. He triages reports, fixes them and publishes the
advisories.

Published advisories: [Security Advisories](https://github.com/Softeria/ms-365-mcp-server/security/advisories)

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly through **GitHub Private Vulnerability Reporting (PVR)**.

**To report**: Go to the [Security Advisories page](../../security/advisories/new)
and submit a new advisory.

Please **do not** open public issues for security vulnerabilities.
